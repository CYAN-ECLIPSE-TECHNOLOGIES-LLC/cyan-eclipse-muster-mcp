## What is being benched

The MUSTER-26 delta only: Muster previously shipped with NO licence check (verified 2026-11-16, STATE-CHECK.md readiness census item 6: "License Server leg — GAP: none wired"). This delta adds licence.py implementing the house License Server model-B posture (estate pattern: Folio L-3 · Loom ETO-22 · Plumb PLU-16) with ONE named boundary, PAID_BOUNDARY_FEATURE = "graph_mutation", consulted as the first statement of the six write-class handlers in server.py (record_ingest, reply_draft, merge_propose, merge_execute, merge_unmerge, retention_sweep). The gate is armed only by explicit configuration (env ECLIPSE_MUSTER_LICENCE_STATE, or a policy.json "licence" block; ECLIPSE_MUSTER_LICENCE_URL / block server_url override the server URL). Unconfigured installs hold no gate object at all and behave exactly as v0.1.1. Reads (record_read, record_search) and diagnostics (policy_show, receipt_list) are never gated. A PASS would unblock: the licence leg being counted as wired for Muster's production-readiness census, at fixture scope. Nothing here claims production, live-for-customers, or certification. No price exists for Muster and none is stated anywhere in this delta.

Boundary rationale (owner-revisable): the gated class is exactly Muster's priced surface class — the operations that create, mutate, merge, draft from, or destroy graph value (tiers T1–T3). Reads stay open in every licence state per the S12 posture every other product ships (post-revocation and post-suspension, existing work stays readable); policy_show / receipt_list stay open because they are the surfaces that display the gate's own refusal evidence (the licence_refused receipts live in receipt_list).

Named test adaptation A1 (the only one): tests/test_muster.py TestP11.test_stdlib_only_imports is EXTENDED, not weakened — the stdlib-only census (MUS-GEN-003) now runs over licence.py as well as server.py, and server.py may import exactly one first-party sibling, "licence", which ships beside server.py via the pyproject force-include list (itself census-tested).
